# EASYBLACK

Official portfolio website for contemporary painter Easyblack.

## Artist

Easyblack is a Nigerian-born, Poland-based self-taught painter working primarily in oil on canvas.

His practice is centered on Narrative Illusionism — a visual language that constructs portraits and identities through fragmented imagery.

## Website Features

- Fullscreen gallery
- Dynamic artwork catalogue
- Collection archives
- Individual artwork pages
- Artist biography
- Exhibition information
- Contact inquiry system
